> "5.1. Q: What are BW, SF, and CR?"

- Mesh definitely uses chirp spread spectrum to encode data, SF (spread factor 
  is a measure specifically for Chirp Spread Spectrum: https://www.thethingsnetwork.org/docs/lorawan/spreading-factors/

> "Recently, as of October 2025, many regions have moved to the "narrow" setting, aka using BW62.5 and a lower SF number (instead of the original SF11). For example, USA/Canada (Recommended) preset is 910.525MHz, SF7, BW62.5, CR5."

- US Meshcore uses SF7, BW 62.5 and CR 5. I wonder if this is able to be
